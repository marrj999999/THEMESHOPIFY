# REF-C: Video Reference List — Build to Bond

## REFERENCE DOCUMENT

> **Build to Bond**  |  **REF-C**  |  **Video Reference List for Instructors**
> This list covers reference video content relevant to each stage of the programme. Videos are for instructor preparation only — they cannot be shown in the workshop setting. Use them to sharpen your own technique before teaching each topic.

## How to Use This List

- Watch relevant videos before each session — not during

- Use the techniques you observe to inform your in-session demonstrations

- If a video contradicts the specific technique or safety rule in this programme, follow the programme. The programme is adapted for this setting.
