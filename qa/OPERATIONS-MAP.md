## Suggested band layout (mobile-first)

**Recommendation: grouped list, not a world map.** Reasons: (a) a dot map at mobile width makes the 4 UK prisons + London cluster illegible; (b) several entries are programmes/partnerships, not pins (Kenya 2019, Rwanda partnership, 45 kit countries) — pinning them overstates permanence, which the Verified-2026 audit explicitly warned about ("training hubs" correction); (c) the repo memory notes mobile viewport can't be visually verified, so favour a layout that degrades safely.

- **Structure:** one band, four stacked groups with count badges — "In prisons (4 sites)" · "In schools & universities (UK)" · "Public workshops (London · Amersfoort · Toulouse [· Munich])" · "Around the world (Kenya 2019 · Rwanda 2024 · kits built in 45 countries)".
- Each group = heading + one-line stranger-clear description + 3–6 name chips (no logos needed). Chips that have a blog story link to it — the evidence URLs above are all live canonical URLs.
- **Kicker stat row:** 4,000+ builders · 45 countries · 4 prison sites · since 2012 (all Proof Bank-verified).
- Desktop enhancement (optional, later): the grouped list can sit beside a simple non-interactive world outline with region highlights (UK / NL / FR / DE / SE / KE / RW) — highlights, not pins, so one-off programmes aren't misread as permanent sites.
- **Wording care:** "We've taught in..." for one-offs (Falun, The Hague, Kenya) vs "We run..." for standing operations (London, prisons, LSBU, Amersfoort, Toulouse). Never "our labs in Ethiopia".
